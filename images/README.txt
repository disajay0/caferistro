FILENAMES MUST BE EXACTLY THESE (lowercase, .jpeg not .jpg):

logo.png
storefront.jpeg   -> hero background
shot-1.jpeg       -> gallery
shot-2.jpeg       -> gallery
shot-3.jpeg       -> gallery

HEIF/HEIC files from an iPhone will NOT display in a browser.
Convert them: select in Finder -> right click -> Quick Actions -> Convert Image
-> Format JPEG, Image Size Large. Renaming the extension does not work.
